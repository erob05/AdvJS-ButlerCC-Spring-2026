Here's the API I was using for this exercise.

const express = require('express');
const app = express();
const dater = require('./dater');

This is index.js in the root folder. The first two lines call in express so I can make a server easily. The third line calls in my dater.js file. Here's what inside dater.js: 

const dater = (req, res, next) => {
    const today = new Date(); // creates Date object
    const yyyy = today.getFullYear(); // assigns the getFullYear property from the Date object to 'yyyy'
    let mm = today.getMonth() + 1; // assigns the getMonth property to the Date object and adds 1 since months start at 0
    let dd = today.getDate(); // assigns the getDate property to dd

    if (dd < 10) dd = '0' + dd; // if dd is a single digit, add a leading zero
    if (mm < 10) mm = '0' + mm; // if mm is a single digit, add a leading zero

    req.formattedToday = mm + '/' + dd + '/' + yyyy; // forms the date and sends as it as part of the request object (I changed it to mm/dd/yyyy)
    next();
}

module.exports = dater;

This code uses the built-in Date object to grab dynamic data. It makes a quick check to see if the day/month is a single digit, if so it adds a leading zero. Then, it formats it all together and exports the dater function. 

const logger = require('./logger');

This line requires the logger.js file. Here what's inside logger.js: 

// first middleware function
const logger = (req, res, next)=>{
    console.log("Logged."); // writes 'Logged' in the console
    next(); // tells the server to move on to the next middleware function
}

module.exports = logger;

This is another middleware function that logs a string in the console and tell the program to move on. 

const info = require('./routes/routeInfo');

This line requires the routeInfo file thats stored inside the routes folder. Here's what inside routeInfo.js: 

const express = require('express');
const router = express.Router();
const {getInfo, selectSingle} = require('../controller/infoCon');

router.get('/',getInfo);
router.get('/:id',selectSingle);

module.exports = router;

This is route file. It'll connect the info and info/:id URLs to controller functions. Here are the controller functions inside the infoCon.js file: 

const {items} = require('../data');

const getInfo = (req,res)=> {
    res.status(200).json({items});
    res.end;
};

const selectSingle = (req,res)=> {
    const {id} = req.params;
    const singleItem = items.find((item) => item.id === Number(id));
    res.json(singleItem);
};

module.exports = { getInfo, selectSingle };

This imports the API and getInfo returns all items from the API. selectSingle returns one item based on the id in the URL. Finally, it exports both functions. 

app.use(dater);
app.use('/info', info);

// Routes
app.get('/', dater, logger, (req,res)=>{
    //res.status(200).send('Home');
    return res.status(200).send(`Welcome! Today's date is ${req.formattedToday}.`);
    res.end;
});

app.listen(8080,()=>{
    console.log('Server running at http://localhost:8080/');
});

The first two lines uses the dater.js middleware function and info routes. The next line defines the homepage route. It'll fire off the dater.js and logger.js middleware functions before sending the string containing today's date to the page. Finally, the last line starts the server on port 8080.
